# Dastaan 🍽️

Dastaan is a modern and responsive restaurant website designed to give the restaurant a strong digital presence and provide customers with a seamless way to explore, discover, and order.

## Features

- Modern and responsive restaurant website
- Elegant and user-friendly interface
- Home page with restaurant highlights
- Dedicated menu page
- Restaurant and food gallery
- Our Story page
- Order Now page
- WhatsApp integration for direct customer communication
- Swiggy integration for online food ordering
- Zomato integration for online food ordering
- Fully responsive across mobile, tablet, and desktop
- Reusable React components
- Fast and optimized frontend experience

## Getting Started

Clone the repository:

git clone https://github.com/AditiSinghTomar1126/Dastaan.git

Navigate to the project:

cd Dastaan

Install dependencies:

npm install

Start the development server:

npm run dev

The application will run at:

http://localhost:3000

## Project Structure

The project follows a component-based Next.js architecture with dedicated pages and reusable components for different sections of the restaurant website.
